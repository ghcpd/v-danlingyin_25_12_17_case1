# Podcast App

A modern, accessible podcast listening web app built with React + TypeScript + Tailwind CSS and Vite.

## Tech Stack
- React 18
- TypeScript (strict)
- Tailwind CSS
- Vite
- pnpm

## Installation
pnpm install

## Development
pnpm dev

## Build
pnpm build

## Project Structure
See `src/` for components, pages, hooks, context, utils and mock data.

## Features Implemented
- Homepage with hero, trending, categories, recently added
- Podcast detail page with episodes and subscribe
- Global audio player (play/pause/seek/volume/next/prev)
- Search with debounce and filters
- Library with subscriptions, favorites, history (localStorage)
- Responsive design and accessibility basics

## Validation
Run `pnpm run validate` or `node validate_project.js`
Run tests with `pnpm test`
